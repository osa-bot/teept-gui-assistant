# TEEPT GUI Assistant

## Overview
TEEPT GUI Assistant is an interactive task automation system that enables users to complete desktop tasks through an intelligent server-guided workflow. The system captures screenshots, analyzes UI elements, and provides visual guidance to users through an on-screen grid interface. It combines multiple detection methods including text-based OCR matching and image-based vision-language model analysis to locate and interact with UI components.

## Purpose
The project is designed to automate and guide users through complex desktop tasks by:

- Establishing communication with a server to receive task instructions and action plans
- Capturing and analyzing screenshots to identify UI elements and their properties
- Matching user-provided descriptions to detected UI components using transliteration-aware text comparison and visual similarity analysis
- Providing real-time visual feedback through grid-based overlays that map screen regions to actionable areas
- Monitoring user interactions to confirm task completion and maintain conversation history with the server for iterative task execution

This system bridges the gap between automated task planning and user-guided execution, enabling efficient completion of GUI-based workflows through intelligent element detection and interactive guidance.
